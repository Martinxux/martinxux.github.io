关于 http.postbuffer的问题

  • 将其提高到默认值以上可能会增加较大推送的延迟（因为客户端会将 HTTP 请求缓冲为较大的区块）。
  • 如果将其设置为大于 HTTP 服务器的 HTTP 区块大小限制（例如 TFS 服务器的web.config中的maxAllowedContentLength和maxRequestLength），则大于区块大小限制的所有推送都将开始失败。
